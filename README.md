# 汉语修辞学 · 期末复习（公开版）

一个单文件、离线可用的《汉语修辞学》期末复习网页，供本科课程复习使用。按课程教学大纲的知识点顺序组织，共 7 个模块、98 个知识点、107 道自测题。

A self-contained, offline-capable HTML review site for the undergraduate course *Chinese Rhetoric* (《汉语修辞学》), organized by the course syllabus: 7 modules, 98 knowledge points, 107 self-test questions.

## 在线访问 / Online

GitHub Pages：https://lm7644.github.io/rhetoric-review/

## 本地使用 / Local

双击 `index.html` 即可（无任何外部依赖，无需联网）。`continuous.html` 为连续排版版，供整本打印或通读。

## 功能 / Features

- 三级目录（模块 → 教材章 → 知识点）＋ hash 路由（`#/m4/s1/m4-08`），刷新与分享可回到原位
- 全文检索、上一页/下一页、键盘 ←/→ 翻页、`/` 聚焦检索
- 重点标记与正文高亮（保存在浏览器本机）、"只看重点"过滤、阅读位置记忆
- 每个知识点含：教材要点（保留必要原文并注明出处页码）、要点整理、部分概念附"通俗说"类比、重点辞格附"对比看"
- 概念索引页（`#/index`）与整本打印视图（`#/all`）
